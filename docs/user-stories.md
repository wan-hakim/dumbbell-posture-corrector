# User Stories

1. As a beginner home fitness enthusiast, I want to receive immediate visual feedback on my dumbbell exercise posture while working out, so that I can correct my form in real-time and avoid musculoskeletal injuries.
2. As a university student working out in my dorm room, I want an automated posture monitoring application that runs smoothly on my standard laptop webcam, so that I can practice safe weightlifting without purchasing expensive depth sensors or high-end GPU hardware.
3. As a casual gym-goer exercising without a personal trainer, I want the system to continuously track my joint movement range and count my repetitions, so that I can ensure maximum muscle engagement and monitor my performance quality over time.
